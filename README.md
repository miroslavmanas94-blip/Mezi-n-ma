# Mezi námi

Responzivní česká hra Pravda, nebo úkol pro dva dospělé hráče.

## Spuštění
Otevřete `index.html` v moderním prohlížeči. Projekt nemá build krok ani serverovou databázi.

## Funkce
- Romantika, zábava, odvážné výzvy, partnerský režim, 18+ smyslnost a náhodný mix
- Střídání hráčů, Pravda/Úkol a náhodná ruleta
- Vlastní otázky a úkoly uložené v místním úložišti
- Dobrovolný časovač a zvukové efekty
- Vypínání kategorií, přístupné ovládání a podpora omezených animací

## Soukromí
Historie her se neukládá. Vlastní výzvy zůstávají v localStorage tohoto prohlížeče. Aplikace je určena pouze dospělým od 18 let.
