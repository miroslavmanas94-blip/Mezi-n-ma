# Mezi námi

Romantická webová hra **Pravda nebo úkol** pro dva dospělé hráče (dívka + chlapec).

## Funkce

- 6 herních režimů (Romantika, Zábava, Odvážné, Partnerský, 18+, Náhodný mix)
- 4 úrovně intenzity
- Střídání hráčů, losování, přeskočení bez trestu
- Vlastní otázky a úkoly (localStorage)
- Responzivní design, romantická vizuální identita (vínová, červená, krémová)
- Bez registrace, bez backendu, data zůstávají v zařízení
- 18+ režim s dobrovolnými intimními výzvami (vždy lze přeskočit)

## Spuštění

Otevřete `index.html` přímo v prohlížeči, nebo:

```bash
npx serve .
```

## Počet položek

Aplikace obsahuje základní sadu originálních otázek a úkolů + generované variace napříč kategoriemi a intenzitami. Systém podporuje přidávání vlastního obsahu a je připravený na rozšíření na plných 250 pravd + 250 úkolů.

## Bezpečnost a souhlas

- Každá výzva je dobrovolná
- Přeskočení je neomezené a bez trestu
- Hráči mohou kdykoli snížit intenzitu nebo vypnout kategorie
- Žádná data se neodesílají na server
